# docs 文档导航

> 整理日期：2026-10-23。当前业务阶段：H3 完整历史搜索，随后 H4 定位；本次整理不改变代码或功能状态。

## 接手顺序

1. 先读根目录 [AGENTS](../AGENTS.md)，再读 [HANDOFF](HANDOFF.md)：确认当前状态、验证欠项和下一步。
2. 读 [11 后续目标](11-next-goals.md)：确认阶段范围、起点与完成标准。
3. 改代码前读 [02 §3 十条不变式](02-handoff.md#3-改代码前必须知道的十条不变式)，再按功能查 [06 开发指导](06-development-guide.md)。
4. 核对 [04 变更记录](04-changes.md) 对应日期的实际证据，不将历史测试数字当成本轮结果。

## 维护规则

每阶段更新 HANDOFF 和 04；目标或顺序变化更新 11，需求边界变化更新 09。实现确实改变结构或协议时再更新对应专页。避免在多份文档追加相同的滚动进度；保留历史证据的日期和适用范围，不维护日常测试总数。
