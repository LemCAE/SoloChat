# LESSONS｜长期工程约束与经验

> 本文件提炼持续有效的规则与原因。详细专题步骤按需查阅 [reference](reference/)；旧方案和故障取证见 [archive](archive/INDEX.md)。

## 会话、写入与播出

- 同一会话由应用级 `SessionRegistry` 唯一持有一个 `SessionController`。页面离开只解除订阅，不关闭控制器或取消生成/播出。发送、push、模式/模型/人物配置等操作须沿同一调度和会话锁，避免双写和竞态。
- 一件状态只能有一个权威写入者。生成落盘事件与异步播出分离；播出按事件逐条推进，每条完成后刷新投影，播出期间不重载整条时间轴。
- UI 与上下文只认出口事件：`DELIVERED`、`INTERRUPTED` 为 spoken；`PENDING`、`PLAYING` 不展示为已说出，未轮到播出的事件取消为 `CANCELED`。中断、超时、失败和用户取消语义不可混用；不要把超时伪装成用户取消。
- 调试/网页命令若要等价于 UI，必须复用同一控制器和命令入口。旧测试网关的直达执行器路径不等价于 UI；reset 只能新建测试会话，不得删除已有资料。

## 上下文、提示词与记账

- `core` 为纯 Kotlin JVM，禁止 `android.*`；Android/Room/Compose 依赖只能由 `app` 实现 core 定义的端口。
- 稳定 system 前缀及 `stablePrefixChars` 口径必须逐字节一致；每轮变化内容放动态区。历史顺序、模式信息和已应用摘要按当前 ContextPlan 装配，统计预览与真实请求快照不能混称。
- 只有明确推送给模型的用户消息才算模型上下文；`sentToModel=false` 是代发状态，不得搜索或界面操作时静默改写。
- 沿用 `call_record` 独立记账。各 token 字段分别标接口返回/本地估算/未知；未知不补 0。调用开始时冻结模型配置和价格，改价、时区或时段不能重算历史费用。

## 用户资料与迁移

- 人物按会话明确关联的有效 ID 解析；缺失时要求选择并阻止生成，不静默回退或改历史归属。真实对话可能自动写人物记忆，验收使用独立测试人物和明确命名的新会话；测试资料默认保留。
- 备份/恢复不得覆盖或合并真实会话。恢复以新 ID 导入副本，完整校验后单事务写入；Key、网页密码、日志与临时凭据不进入备份。迁移只增不改，禁止破坏性 fallback。
- 任何历史数据迁移、修复或清理都先保留修改前后数据库一致副本（含 WAL/SHM），按主键逐行核对既有记录：原有行改动/消失为零，新行另计。比较判据须独立于被测实现。

## 发布、签名与验证口径

- 本机预览和发行版都使用 `app.solochat` 与同一发布签名，以覆盖升级并沿用资料。不得为适配签名卸载旧包或清数据；历史 `.debug` 不能作为默认装机包。生成预览前读取设备当前版本码。
- 构建使用 `tools/build.ps1`，遵循仓库环境约束；密钥只从本地忽略文件/环境注入，绝不写入源码、文档或日志。
- 先取证再下结论：JVM/CI、真实模型输出、真机交互、长期质量分别陈述。只做与本次改动正确性/资料安全有关的最小必要验证；未做的路径明确标为未验证。短对话不证明百轮质量，编译通过不证明设备体验。
- 对话真机验收只用新建的专用测试会话，不改真实会话、旧消息、模式或人物归属。测试后的专用资料默认保留并说明用途。

## 改文档与源码

源码和当前有效文档优先于旧审计结论；注释必须与实现一致。用户界面文案不用第三人称性别代词。整体视觉语言或全局布局变更须先经用户批准；已明确反馈的局部改进按范围处理。
