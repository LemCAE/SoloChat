## 实施边界

`ReferencePrices` 只供 UI 查阅及显式复制，价格解析器不引用它。可复制项另建新 ID，先加入当前组草稿，保存才参与后续计价；旧 assets/data/model-prices.json 及 initialCatalog 继续用于旧配置兼容，不被新资料替换。没有 Room、历史账目或用户表迁移。同名模型不跨渠道套价。
