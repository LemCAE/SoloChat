- 长会话、连续长场景和超大库：按具体问题与调用预算安排，不因短检查宣称长期质量。
- U3 系统更新链路及跨安装备份恢复：仍有端到端实机欠项。
- 备份人物归属：R4 定向检查发现旧用例“默认归属会话导入后固定到备份中的人物卡副本”失败；当前代码要求明确人物 ID，与该用例的隐式默认预期不一致。本轮未改该路径，需单独核对旧备份兼容意图，不能据此断言用户资料已损坏。

整体视觉风格改版、时间功能、自动压缩、云同步、图片与语音沿用既有暂缓边界；本轮只完成局部文案与布局精修。
