## 后续设计事项

### P0｜R1～R3 价格表与提供商配置

范围确认：当前只优先支持 **DeepSeek 官方、阿里云百炼**，同时保留自定义 OpenAI 兼容接口。参考 Rikkahub 的提供商 → 组内模型组织与编辑入口，不默认加入其他厂商，不照搬其视觉主题。当前全局选组、会话只覆盖模型名的规则保持不变。

- **R1（当前阶段）**：添加组时提供上述三个入口，移除编辑页“填入 DashScope 地址”；价格页显式新建表、新增模型价格、导入/导出单表 JSON；随包资料分离为只读参考，明确复制才进入本组草稿。旧表及已有修改保留，不进行历史账目迁移。格式与示例见 [自定义价格表](reference/price-table-format.md)。验证结果记录在 HANDOFF。
- **R2（下一阶段）**：重整提供商详情与价格主页面，以当前组的模型列表和模型价格条目为主，手动添加 / 目录选择、逐模型编辑、表管理入口清楚分开；本组兜底价降为可选设置。先给出具体页面方案，再做局部重写；保持现有模型覆盖、草稿保存与调用价格冻结约束，不顺带改全局风格。
- **R3（R2 之后）**：重写参考价格资料，先聚焦 DeepSeek 官方和百炼，逐条核对来源日期、币种/单位、模型 ID、缓存与峰谷语义后再整理。参考资料与用户组内实价始终分离，不按相同模型名跨渠道套价；不静默替换旧表或用户编辑。此项尚未采集新报价，不把原随包快照当成当前官方价格。

正式局域网网页、按上下文主动消息、多模型群聊均先明确鉴权/幂等/费用/打断/备份边界；不在本计划中视为已排期实现。长会话质量按具体问题与调用预算单独安排。整体 UI 风格、时间功能、自动压缩、云同步、图片与语音维持既有暂缓边界。
