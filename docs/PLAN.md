# PLAN｜当前开发计划

> 更新：2026-10-23。只列已确认的未完成目标；历史阶段计划见 [归档索引](archive/INDEX.md)。计划不代表实现。

## P0｜H3 完整历史搜索

从当前会话搜索开始，再扩展到全局会话。直接查完整数据库，使用有界分页结果并附带稳定来源定位键；沿用统一时间轴可见性，排除记忆、等待提示及未出口/取消事件，避免助手事件与消息副本重复。正确转义 LIKE 的 `%`、`_` 和转义符。不请求模型，不修改消息、摘要、记忆使用次数、sentToModel 或历史账目。

验收：中文、emoji、重复文本和特殊字符；压缩前历史仍可查；隐藏/未出口内容不可命中；搜索范围覆盖未加载页；空词、无结果、失败和结果变化可恢复。优先当前会话，再接全局范围。按影响选择定向测试；涉及交互时用专用测试会话。

## P1｜H4 搜索结果定位

点击结果后按目标加载前后文并高亮，可返回最新；不无限逐页回溯，不打断正在播放的活气泡。定位期间新内容仍遵循阅读位置保护。

验收：跨页定位、目标已删除、播出中定位/返回；保留草稿与搜索条件；按来源类型+ID 区分 message/event，目标失效时可返回搜索结果或最新记录。

## P2｜多组 baseURL/API Key

历史链路完成后再做配置迁移、分组编辑与显式切换、模型目录/连通测试接入。现有配置迁移为一组；地址与密钥成对选择，密钥加密存储，不进日志、仓库或备份。请求开始时冻结配置；切换不得改写进行中调用，缺凭据不得偷偷回退到其他组。

验收：旧配置不丢失；无效地址/空密钥可恢复；后续请求使用新组、进行中请求维持原配置；配置删除不触发调用；沿用现有调用账目和冻结价格。实施前先决定全局配置组与会话模型覆盖、默认模型和价格归属。

## 后续设计事项

正式局域网网页、按上下文主动消息、多模型群聊均先明确鉴权/幂等/费用/打断/备份边界；不在本计划中视为已排期实现。长会话质量按具体问题与调用预算单独安排。整体 UI 风格、时间功能、自动压缩、云同步、图片与语音维持既有暂缓边界。
