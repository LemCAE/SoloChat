# SoloChat

私人自用的 Android 角色聊天应用，目标是像在微信里与一个人聊天。无需账号或中间服务器，使用自行配置的大模型接口；聊天资料保存在本机，请求上下文会发送给所选模型服务商。

[下载 APK](https://github.com/LemCAE/SoloChat/releases) · [使用与开发文档](#文档) · [变更记录](docs/archive/04-changes.md)

## 功能概览

- **有节奏的回复**：模型每轮返回事件脚本，应用按节奏播放对白、动作与场景，支持连续输入、防抖和插话。
- **两种交流模式**：同一会话可在发消息与面对面之间切换，保留共同历史。
- **人物与记忆**：按人物浏览多段对话，自定义人物卡、文字或图片头像；同一人物的会话共享人物记忆。
- **上下文管理**：手动压缩早期历史，预览、编辑和应用摘要，也可恢复原文；原始聊天记录保留。
- **历史搜索**：聊天标题栏可搜当前会话，首页/人物会话列表标题栏可搜全部会话（含归档），全局结果标明人物和会话名。按原文区分大小写匹配，支持分页、刷新和命中高亮；不请求模型。
- **记录定位**：点击搜索结果，查看目标附近的原始记录并高亮，可继续加载前后文、返回搜索或查看最新记录。定位页只读，不自动推送代发；新消息只提示，不移动阅读位置。
- **用量与价格**：逐调用保存输入、输出、缓存、推理明细和调用时价格；支持多价格表、自定义单价与逐模型峰谷计价。
- **本地备份**：导出 ZIP 并恢复为独立副本，支持从旧安装迁移资料。

## 快速开始

### 1. 安装

从 [Releases](https://github.com/LemCAE/SoloChat/releases) 下载 `app-release.apk`，在 Android 8.0 或更新系统上安装。

正式版、预发布和本机开发预览统一使用 **`app.solochat` 与同一发布签名**，覆盖升级可沿用资料。不要为解决签名不一致卸载应用或清除数据。历史 `app.solochat.debug` 是独立安装，资料迁移见[备份与恢复](#备份与恢复)。

### 2. 配置模型接口

打开右上角菜单 → **设置 → 模型接口**，填写并保存：

| 设置 | 说明 |
|---|---|
| Base URL | OpenAI 兼容接口地址，例如 `https://api.deepseek.com` |
| API Key | 模型服务商密钥，使用 Android Keystore 加密保存 |
| 模型 | 获取模型列表，或手动填写已开通的模型名 |

“测试连通”使用当前草稿发起请求，可能产生少量模型用量；保存后配置才生效。离页可选择保存、放弃或继续编辑。会话可单独指定模型，接口与密钥仍继承全局配置。

**DashScope**：填写 `https://dashscope.aliyuncs.com/compatible-mode/v1`，或使用页面的快捷地址按钮，再填写相应地域的 Key 与模型名。聊天兼容流式返回、思考内容和独立用量帧；模型列表使用同域原生目录接口及分页。目录中存在模型不代表账号已获调用权限，仍可手填名称。

### 3. 创建对话

首页 **+** → 选择人物卡 → 创建对话。首页只显示已有对话的人物，进入人物后可查看或新建多段对话。原人物已删除或未明确选择的对话归入“待确认人物”，重新选卡后才能继续发送。

- **自动发送**：连续输入经过防抖后交给模型。
- **手动发送**：先保存代发消息，再按推送交给模型。
- **会话设置**：修改名称、选择模型、进入上下文管理及用量统计；删除对话需确认。
- **离开聊天页**：应用进程存活时，已开始的生成与播出继续进行；重进会话可观察状态。

## 聊天模式与命令

| 模式 | 内容 | 输入 |
|---|---|---|
| 发消息 `chat` | 按节奏出现的聊天气泡 | 说话 |
| 面对面 `scene` | 对白、动作、环境旁白 | 说话、动作或环境 |

模型可提议切换模式，确认后生效，也可关闭模式提议。输入 `/` 可查看命令：

| 命令 | 行为 |
|---|---|
| `/scene` | 直接切换为面对面，并调用模型开场 |
| `/chat` | 直接切换为发消息，并调用模型开场 |
| `/system 现在是晚上，外面开始下雨` | 保存系统事实，下一轮读取，不立即调用模型 |
| `/compress` | 打开上下文压缩，先选择范围并预览 |

精确的 `/system 进入面对面模式`、`/system 切换到聊天模式` 也直接切换。相同模式不重复开场；普通系统事实不靠关键词猜测是否切换。

## 人物卡与记忆

仓库的 `personas/` 收录 [小鲸鱼](personas/小鲸鱼.md)，应用也提供小鲸鱼随包模板。其他本机人物文件不纳入 Git；新会话必须明确选卡，不自动回退。旧安装已有的人物和聊天保留。

人物卡支持八段设定，决定身份、说话方式、面对面语气、动作习惯、环境、描写方式、边界与私有设定。面对面语气、环境和描写方式只在面对面模式注入。可导入 JSON 文档、导出卡片或复制修改，导入创建新卡，不覆盖已有内容。字段与模板见[人物卡格式](docs/reference/03-persona-format.md)。

记忆分为人物专属与通用记忆；模型可提出 `remember` 事件，也可手动添加、固定或删除。每轮只选择部分可用记忆，未选入不表示删除。修改人物或记忆会影响后续上下文，不重写已发生的聊天。

## 价格与用量

**设置 → 模型价格** 首页展示全局所选模型的匹配价格，完整列表在子页。支持模型名搜索及归属/服务商筛选；归属选择面板限高、可搜索并独立滚动。

- 价格表可新增、复制、重命名、删除和编辑，至少保留一张。
- 模型编辑先应用到页面草稿，再保存价格页；取消或放弃不更改配置。
- 每个模型可设置标准价、缓存价、峰价、时段与时区。初始全部关闭峰谷，新模型也默认关闭；开启时须填写有效配置，支持跨午夜。
- 未匹配价格表时使用明确配置的全局自填价；两者都没有则费用未知。已配置的零价表示免费，未单独配置缓存价时按输入价计费。
- 随包价格来自 QQ-agent 快照，可能过时，金额单位为元 / 百万 token；不会自动联网更新。

**首页菜单 → 用量** 可查看今天、近7天、本月或累计；会话设置中可只看本会话。最近调用位于独立子页，点击查看字段来源、原始 usage、冻结单价与费用拆分。

缓存包含在输入内，推理包含在输出内，不重复累计。命中率只计算接口同时返回输入和缓存的调用。价格按调用开始时间冻结，改价不重算历史；未知字段不补零，旧记录不补造价格。费用始终是估算而非服务商账单，失败、取消与静默也保留实际调用尝试，导入历史与本机消费分开。

## 备份与恢复

**设置 → 资料 → 本地备份**：

1. 选择“整理备份”，核对数量和时间，再保存 ZIP。
2. 恢复时选择 ZIP，核对来源、数量、重复导入及通用记忆提示，再确认导入。
3. 导入会话先暂停发送，可只读查看；确认接口和模型配置后，在会话中恢复发送。

备份包含会话、消息、事件、人物、记忆、摘要版本及用量，不含 API Key、接口设置、价格表等偏好、日志和头像图片内容。文件未加密，请妥善保管；备份整理后的新消息需要重新整理才会纳入。

恢复创建独立副本，不覆盖现有资料，失效摘要保留但停用。自动模式下恢复发送可能推送旧代发，手动模式仍需按推送。通用记忆恢复后可用于所有人物。

从历史 `.debug` 安装迁移时，保留旧安装，先导出再到发布版恢复；接口、Key 和价格设置需要重新配置。格式与兼容边界见[备份协议](docs/reference/07-backup-format.md)。

## 开发与构建

| 项目 | 配置 |
|---|---|
| 语言与界面 | Kotlin 2.1、Jetpack Compose、Material 3 |
| Android | minSdk 26，compileSdk / targetSdk 35 |
| 数据 | Room 版本 7、DataStore、加密密钥存储 |
| 网络 | OkHttp；应用内日志与调试服务使用 Ktor |
| 编译 | JDK 21，Java / Kotlin 字节码目标 17 |

```text
SoloChat/
├── core/src/          纯 Kotlin 核心与 JVM 测试，不依赖 Android API
├── app/src/           Android 存储、网络、会话编排、Compose 界面与资源
├── app/schemas/       版本化 Room schema，迁移所需，保留在 Git
├── personas/          唯一公开人物文档：小鲸鱼
├── docs/              设计、交接、使用与开发文档
├── tools/             构建、备份和调试工具
└── gradle/            版本目录与 wrapper
```

动手前先读 [AGENTS.md](AGENTS.md) 和[交接不变式](docs/LESSONS.md)。本机使用 `tools/build.ps1`，由它设置 JDK、工作区缓存和 Android SDK 路径，不直接运行 `gradlew`。

```powershell
# 仅编译检查，debug 包不作为默认安装包
pwsh tools/build.ps1 :app:assembleDebug

# 本机预览：需要忽略目录中的发布签名配置，版本码按当前安装值填写
pwsh tools/build-preview.ps1 -VersionCode <当前安装版本码> -VersionName 0.1.0-local

# 安装同签名的 release 包；USB 和无线连接都可用
adb install -r app/build/outputs/apk/release/app-release.apk
```

首次构建需下载依赖。IDE 输出 `core/bin/`、`app/bin/`，构建目录与本机配置不纳入版本管理；Gradle wrapper、迁移 schema 和业务资源必须保留。签名文件、API Key 与密码不得提交。

### 测试

只运行本次改动需要的检查，不将全量测试、重复装机或取证作为每次提交的门槛。自动测试为纯 JVM JUnit，不能代替真实界面与模型行为检查。

| 改动 | 检查范围 |
|---|---|
| 文档、普通文案 | 直接核对，不默认构建或测试 |
| 解析、计价、状态流转 | 相关测试类；逻辑修复优先使用能复现问题的用例 |
| 键盘、滚动或其他交互 | 对应实机路径，优先正常字体与专用测试资料 |
| 跨模块、影响难以限定 | 按实际风险扩大相关套件，必要时才全量回归 |
| 历史数据迁移、修复或清理 | 按[交接文档](docs/LESSONS.md)增加原记录保护核对 |

```powershell
pwsh tools/build.ps1 :core:test --tests '*PriceCatalogTest'
pwsh tools/build.ps1 :app:testDebugUnitTest --tests '*PricingRulesTest'
```

结论已充分支持后不追加同类验证；不默认 `clean`、`--rerun-tasks` 或真实模型调用。记录实际范围、结果与未确认项，不累计残留测试报告中的总数。

### GitHub 发布

只有发布 Release（含预发布）才触发云端 `:core:test :app:testReleaseUnitTest :app:assembleRelease`；普通推送、PR、标签推送和保存草稿不构建。成功后固定签名的 `app-release.apk` 附到对应 Release。版本名来自标签去掉开头的 `v`，版本码来自工作流运行序号。

仓库 Actions Secrets 需要 `SOLOCHAT_KEYSTORE_BASE64`、`SOLOCHAT_KEYSTORE_PASSWORD`、`SOLOCHAT_KEY_ALIAS`、`SOLOCHAT_KEY_PASSWORD`。密钥应另行备份，丢失后无法以原签名覆盖升级。

### 查询应用更新

设置 → 应用 → 关于与更新 → 检查更新。默认只查正式发布，可开启“包含预发布版本”；检查为手动操作，不后台轮询。页面展示版本、发布时间、说明和安装包是否就绪，失败或限流会明确提示，不显示成“已是最新”。

可点击下载所显示发布的 APK，查看进度、取消并重试；同一时间只运行一个固定版本/asset 的任务，离开页面仍继续。文件放在应用私有缓存中，进程结束后不自动续传；失败或取消后重新下载。下载完成后读取 APK 包名、版本码、当前签名者及最低系统版本，通过预检查才显示“安装”。允许同版本覆盖，拒绝降级或签名不符；证书轮换暂按不一致处理。安装前可进入本地备份，随后交给系统确认；来源授权返回后需再次点击安装，不自动安装或恢复资料。

## 已知限制与规划

- 百轮长会话与连续长场景质量尚未压测，短对话检查不代表长期保证。
- 聊天首次读取最近 80 条可见记录；上翻后可点击“加载更早记录”，保留阅读位置。阅读旧记录时新内容只作提示，点击“返回最新”回到最近一页。当前会话及全局搜索可查未加载的完整历史，每页 40 条。点击结果进入只读定位页，首次读取目标前后各 20 条；该页“返回最新”只读最新记录，继续聊天须返回原聊天页或从会话列表进入。
- 进程内离页可继续生成与播出；系统杀进程后的自动恢复尚未实现。
- 联网搜索、正式局域网网页聊天尚未实现。
- 已支持手动 GitHub 查询、APK 下载与安装预检查，安装由系统确认；不支持静默安装或进程重启自动续传。旧 `.debug` 安装与正式版资料独立，需通过备份手动恢复副本。
- 多组 baseURL/API Key 保存和快速切换已列为后续目标，尚未实现。
- 根据上下文自动发送消息为中期计划，多模型群聊为远期计划，均未启用。
- 当前仅支持 Android。
